# Features

Explore nnsight's capabilities in depth through interactive notebooks.

## Core Features

- **[Getting Activations](1_getting.ipynb)** - Access hidden states and activations from any layer
- **[Setting Activations](2_setting.ipynb)** - Modify activations to study causal effects
- **[Gradients](3_gradients.ipynb)** - Compute gradients with respect to intermediate values
- **[Multiple Token Generation](4_multiple_token.ipynb)** - Work with autoregressive generation
- **[Module Access](5_modules.ipynb)** - Navigate and access model components
- **[Model Editing](6_model_editing.ipynb)** - Create persistent model modifications
- **[Cross-Prompt Intervention](7_cross_prompt.ipynb)** - Transfer activations between different prompts
- **[Empty Invokers](8_empty_invokers.ipynb)** - Run interventions without input data
- **[Intermediate Operations](9_source.ipynb)** - Access intermediate operations inside modules
- **[Early Stopping](10_early_stopping.ipynb)** - Stop computation early for efficiency
- **[Skip Execution](11_skip.ipynb)** - Skip parts of model execution
- **[Scan](12_scan.ipynb)** - Infer shapes without full execution
- **[Remote Execution](13_remote_execution.ipynb)** - Run on NDIF's remote infrastructure
- **[vLLM Support](15_vllm_support.ipynb)** - High-performance inference with vLLM
- **[Cache](16_cache.ipynb)** - Bulk-collect activations from many modules in one pass
