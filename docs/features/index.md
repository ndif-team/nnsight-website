# Features

Explore nnsight's capabilities in depth through interactive notebooks.

## Core Features

- **[Getting Activations](1_getting.ipynb)** - Access hidden states and activations from any layer
- **[Setting Activations](2_setting.ipynb)** - Modify activations to study causal effects
- **[Gradients](3_gradients.ipynb)** - Compute gradients with respect to intermediate values
- **[Multiple Token Generation](4_multiple_token.ipynb)** - Work with autoregressive generation
- **[Loading a Model](5_loading.ipynb)** - Constructor options, meta-model dispatch, and device placement
- **[Module Access](6_modules.ipynb)** - Navigate and access model components
- **[Model Editing](7_model_editing.ipynb)** - Create persistent model modifications
- **[Batching](8_batching.ipynb)** - Combine multiple prompts in one forward pass and move values between them
- **[Empty Invokers](9_empty_invokers.ipynb)** - Run interventions without input data
- **[Cache](10_cache.ipynb)** - Bulk-collect activations from many modules in one pass
- **[Intermediate Operations](11_source.ipynb)** - Access intermediate operations inside modules
- **[Early Stopping](12_early_stopping.ipynb)** - Stop computation early for efficiency
- **[Skip Execution](13_skip.ipynb)** - Skip parts of model execution
- **[Scan](14_scan.ipynb)** - Infer shapes without full execution
- **[Remote Execution](15_remote_execution.ipynb)** - Run on NDIF's remote infrastructure
- **[vLLM Support](16_vllm_support.ipynb)** - High-performance inference with vLLM
